# Marvin Averill — Portfolio

Plain HTML/CSS portfolio site. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works as-is).

## Folders

| Folder | What's inside |
|---|---|
| `index.html` | Home page |
| `about/` | About page |
| `work/` | Work gallery page |
| `case/` | Case study pages (Sphere, Blieve, Capitareward, Carbon, Fuhh) and their stylesheet |
| `css/` | Shared site stylesheet |
| `assets/icons/` | Logo and social icons |
| `assets/images/` | Site background and portrait images |
| `assets/js/` | Site scripts (menu, lightbox) |
| `images/` | Project and case study pictures |
